Exam Photo & Signature Size Guide

Compare photo, signature, pixel and KB requirements for Indian examination forms.

There is no universal photo or signature size for every Indian examination. Requirements change by exam and application cycle. Use this as a starting point and verify the current official notice and upload screen.

Photo preparation checklist

  1. Use a recent, clear photograph with face visible and recognisable.
  2. Check background, face framing, lighting, glasses/cap rules and whether live capture is required.
  3. Use the resizer only if the portal requests an image file. It cannot create a live capture.
  4. Check the final preview for blur, distortion, incorrect crop or poor lighting.

Signature preparation checklist

  1. Sign on plain white paper using the ink and layout specified in the notice.
  2. Scan in even light; avoid shadows, glare and ruled paper.
  3. Crop blank margins carefully without distorting the handwriting.
  4. Enter the exact dimensions and KB range in the MailFix resizer.
  5. Check legibility at normal size before uploading.

Pixels versus centimetres

When a notice specifies physical size and DPI, pixels = centimetres ÷ 2.54 × DPI. For example, 6 × 2 cm at 300 DPI is about 709 × 236 pixels. This is a mathematical conversion, not an official pixel requirement unless the notice says so. If no DPI is given, do not invent a mandatory pixel pair.

FAQs

What is the standard size for all government exams?

There is no single standard. Each examination can set different pixel, physical-size, format and KB requirements.

Can the resizer prepare an SSC CGL 2026 photo?

No. SSC CGL 2026 uses live photo capture through the application module. The tool can prepare a signature file.

Does the resizer guarantee acceptance?

No. It checks technical dimensions and file size, not identity, image content or portal validation.
